# Codex Project Instructions

Before planning or implementing any task in this repository:

1. Read every Markdown file in `/docs`.
2. Read `/CONTRIBUTING.md`.
3. Treat `/docs/PROJECT_CONTEXT.md` as the current handoff, then verify its version against `app-meta.js`.
4. Follow `/docs/ARCHITECTURE.md`, `/docs/UI_GUIDELINES.md`, and `/docs/RELEASE_PROCESS.md`.
5. Update the relevant documentation when a task changes product direction, architecture, UI standards, defects, release state, or active sprint goals.

Do not change production behavior during documentation-only tasks.
