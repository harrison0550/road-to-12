# Road to 12% v1.0

Deployment-ready Progressive Web App.

## Deploy with GitHub Pages
1. Create a public GitHub repository named `road-to-12`.
2. Upload the CONTENTS of this folder to the repository root.
3. In repository Settings → Pages, choose `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`.
5. Save. GitHub will show the HTTPS app address after deployment.

## Install on iPhone
1. Open the HTTPS app address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch Road to 12% from the new icon.

## Features
- Personalized dashboard
- Working workout flow
- User gym photos and setup callouts
- Set, rep and weight logging
- Rest timer with vibration where supported
- Exercise and equipment libraries
- Local progress check-ins
- Workout history
- Offline caching after first load

All records are stored locally in Safari on the device. Clearing Safari website data will erase them.
